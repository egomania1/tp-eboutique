Guide Oral — eBoutique PHP MVC

Projet : Application e-boutique en PHP natif, architecture MVC

Objectif de ce guide : Savoir expliquer chaque fonctionnalité et le code correspondant à l'oral.

1. Architecture MVC — Comment est organisé le projet ?

MVC = Modèle / Vue / Contrôleur
C'est une façon d'organiser le code en 3 couches séparées pour que chaque partie ait un rôle précis.
Dossier Rôle Exemple
models/ Accès à la base de données uniquement ProductModel.php, UserModel.php
controllers/ Logique métier, traitement des formulaires AuthController.php, CartController.php
views/ Affichage HTML uniquement catalogue_simple.php, cart.php
index.php Routeur — redirige vers le bon contrôleur ?page=login → AuthController
💬 À dire à l'oral : "J'ai utilisé une architecture MVC pour séparer les responsabilités. Les modèles font les requêtes SQL, les contrôleurs gèrent la logique, et les vues affichent uniquement le HTML. Le fichier index.php joue le rôle de routeur : il lit le paramètre page dans l'URL et charge le bon contrôleur."

Le routeur — index.php

$page = isset($_GET['page']) ? $_GET['page'] : 'home';

switch ($page) {
    case 'login':
        require_once ROOT . 'controllers/AuthController.php';
        break;
    case 'cart':
        require_once ROOT . 'controllers/CartController.php';
        break;
    // ...
}
💬 "On récupère le paramètre page dans l'URL. Si rien n'est précisé, on affiche 'home'. Ensuite le switch charge le bon contrôleur."

2. Connexion à la base de données — config/db.php

$pdo = new PDO("mysql:host=localhost;dbname=eboutique;charset=utf8", "root", "");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
💬 "J'utilise PDO pour me connecter à MySQL. PDO est une interface sécurisée qui permet de faire des requêtes préparées. Le setAttribute active l'affichage des erreurs. La variable $pdo est disponible dans tous les fichiers grâce au require_once dans index.php."

3. Inscription et Connexion — AuthController.php

Inscription

if (isset($_POST['inscription'])) {
    $nom   = trim($_POST['nom']);
    $email = trim($_POST['email']);

    if (empty($nom) || empty($email) || empty($password)) {
        $erreur = "Tous les champs sont obligatoires.";
    } elseif (emailExisteDeja($pdo, $email)) {
        $erreur = "Cet email est déjà utilisé.";
    } else {
        creerUtilisateur($pdo, $nom, $email, $password, $role);
        header('Location: index.php?page=login&message=compte_cree');
        exit();
    }
}
💬 "Quand le formulaire est soumis, on vérifie que les champs ne sont pas vides avec empty(). On vérifie aussi que l'email n'existe pas déjà en base. Si tout est bon, on appelle la fonction creerUtilisateur() du modèle."

Mot de passe hashé — UserModel.php

$passwordHashe = password_hash($password, PASSWORD_DEFAULT);
💬 "On ne stocke jamais un mot de passe en clair en base de données. password_hash() le transforme en une chaîne illisible. Pour vérifier, on utilise password_verify() qui compare le mot de passe tapé avec le hash stocké."

Connexion

$utilisateur = trouverUtilisateurParEmail($pdo, $email);

if ($utilisateur && password_verify($password, $utilisateur['password'])) {
    $_SESSION['user_id']   = $utilisateur['id'];
    $_SESSION['user_nom']  = $utilisateur['nom'];
    $_SESSION['user_role'] = $utilisateur['role'];
    header('Location: index.php?page=home');
    exit();
}
💬 "On cherche l'utilisateur par son email. Si il existe et que le mot de passe correspond, on stocke ses infos dans la session. La session permet de garder ces informations sur toutes les pages."

4. Sessions — Gestion de l'utilisateur connecté

// Démarrer la session (dans index.php)
session_start();

// Stocker une info
$_SESSION['user_id'] = $utilisateur['id'];

// Vérifier si connecté
if (!isset($_SESSION['user_id'])) {
    header('Location: index.php?page=login');
    exit();
}

// Détruire la session (déconnexion)
session_destroy();
💬 "La session PHP permet de conserver des données entre les différentes pages du site. session_start() doit être appelé au début de chaque page. On vérifie si l'utilisateur est connecté avec isset($_SESSION['user_id']). Pour se déconnecter, session_destroy() supprime toutes les données."

5. Requêtes préparées — Sécurité SQL

// Exemple dans UserModel.php
$req = $pdo->prepare("SELECT * FROM users WHERE email = :email");
$req->execute([':email' => $email]);
$utilisateur = $req->fetch();
💬 "Les requêtes préparées protègent contre les injections SQL. Au lieu d'insérer directement les variables dans la requête (ce qui serait dangereux), on utilise des paramètres avec ':email'. PDO remplace ces paramètres de façon sécurisée lors de l'exécution."

6. Gestion des rôles — Client / Vendeur

// Stocké dans la session à la connexion
$_SESSION['user_role'] = $utilisateur['role']; // 'client' ou 'vendeur'

// Dans la vue : afficher le bouton vendeur seulement si vendeur
if ($_SESSION['user_role'] === 'vendeur') {
    echo '<a href="index.php?page=add_product">+ Ajouter un produit</a>';
}

// Dans add_product.php : bloquer l'accès si pas vendeur
if (!isset($_SESSION['user_role']) || $_SESSION['user_role'] !== 'vendeur') {
    header('Location: index.php?page=home');
    exit();
}
💬 "Le rôle est stocké en session à la connexion. On l'utilise pour restreindre l'accès : un client ne peut pas accéder à la page d'ajout de produit. Si quelqu'un essaie d'accéder directement à l'URL, il est redirigé vers l'accueil."

7. Catalogue de produits — ProductController + ProductModel

Requête SQL avec JOIN

// ProductModel.php
function getProduitsParCategorie($pdo) {
    $req = $pdo->prepare("
        SELECT p.*, c.nom AS categorie_nom
        FROM products p
        JOIN categories c ON p.categorie_id = c.id
        ORDER BY c.nom, p.nom
    ");
    $req->execute();
    $tous = $req->fetchAll();

    // On regroupe les produits par catégorie
    $groupes = [];
    foreach ($tous as $p) {
        $groupes[$p['categorie_nom']][] = $p;
    }
    return $groupes;
}
💬 "On utilise un JOIN pour récupérer les produits avec le nom de leur catégorie en une seule requête. Ensuite on regroupe les produits dans un tableau indexé par catégorie avec foreach. Ce tableau est passé à la vue qui l'affiche catégorie par catégorie."

Affichage dans la vue

foreach ($produitsParCategorie as $categorie => $produits):
    echo '<h2>' . htmlspecialchars($categorie) . '</h2>';
    foreach ($produits as $p):
        echo htmlspecialchars($p['nom']);
    endforeach;
endforeach;
💬 "htmlspecialchars() protège contre les attaques XSS en transformant les caractères spéciaux HTML en entités. On l'applique sur toutes les données venant de la base avant de les afficher."

8. Upload d'image — Ajout de produit

// ProductController.php
if ($_FILES['image']['error'] === 0) {

    $extension = strtolower(pathinfo($_FILES['image']['name'], PATHINFO_EXTENSION));
    $extensionsAutorisees = ['jpg', 'jpeg', 'png', 'gif'];

    if (!in_array($extension, $extensionsAutorisees)) {
        $erreur = "Seules les images JPG, PNG et GIF sont acceptées.";

    } elseif ($_FILES['image']['size'] > 2 * 1024 * 1024) {
        $erreur = "L'image ne doit pas dépasser 2 Mo.";

    } else {
        $nomUnique = uniqid() . '.' . $extension;
        move_uploaded_file($_FILES['image']['tmp_name'], ROOT . 'uploads/' . $nomUnique);
    }
}
💬 "$_FILES contient les informations du fichier envoyé. On vérifie d'abord l'extension avec pathinfo() pour n'accepter que les images. On vérifie la taille (2 Mo max). uniqid() génère un nom unique pour éviter d'écraser un fichier existant. move_uploaded_file() déplace le fichier temporaire vers le dossier uploads/."

9. Panier — CartController.php

// Initialisation du panier en session
if (!isset($_SESSION['panier'])) {
    $_SESSION['panier'] = [];
}

// Ajouter un produit
if (isset($_SESSION['panier'][$produit_id])) {
    $_SESSION['panier'][$produit_id]['quantite']++;
} else {
    $_SESSION['panier'][$produit_id] = [
        'nom'      => $produit['nom'],
        'prix'     => $produit['prix'],
        'quantite' => 1
    ];
}

// Calculer le total
$total = 0;
foreach ($_SESSION['panier'] as $item) {
    $total += $item['prix'] * $item['quantite'];
}
💬 "Le panier est stocké en session sous forme de tableau. La clé du tableau c'est l'ID du produit. Si le produit est déjà dans le panier, on augmente juste la quantité. Sinon on l'ajoute avec quantité 1. Le total est calculé dans le contrôleur avec une boucle foreach : prix × quantité pour chaque produit."

10. Validation de commande — OrderController.php

if (isset($_POST['valider_commande'])) {

    // Calcul du total
    $total = 0;
    foreach ($_SESSION['panier'] as $item) {
        $total += $item['prix'] * $item['quantite'];
    }

    // Création de la commande en base
    $commande_id = creerCommande($pdo, $_SESSION['user_id'], $total);

    // Ajout de chaque produit dans commande_items
    foreach ($_SESSION['panier'] as $produit_id => $item) {
        ajouterItemCommande($pdo, $commande_id, $produit_id, $item['nom'], $item['prix'], $item['quantite']);
    }

    // On vide le panier
    $_SESSION['panier'] = [];

    header('Location: index.php?page=confirmation&commande_id=' . $commande_id);
    exit();
}
💬 "Quand le client clique sur Valider, on calcule le total, on crée la commande en base avec l'ID de l'utilisateur, puis on enregistre chaque produit dans la table commande_items. On vide ensuite le panier et on redirige vers la page de confirmation."
